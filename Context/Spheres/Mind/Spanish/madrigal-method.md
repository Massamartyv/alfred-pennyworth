# The Madrigal Method — Cognate Conversion and Creation

Reference distilled from Margarita Madrigal's *Magic Key to Spanish* (1951). The book's thesis: an English speaker already owns thousands of Spanish words and can *create* them rather than memorize. This file captures the transferable method. It governs how Alfred gives ambient Spanish support and how the Español tutoring project teaches. The pattern generalizes to the other Romance languages when they activate.

## The two principles

1. **Create, do not memorize.** Forming a word from a known pattern beats recalling it from a list. What is created stays; what is drilled fades.
2. **Build from what you know.** Start every new word from its English cognate where one exists. Confidence first, grammar second.

## Cognate conversion patterns

English suffix to Spanish suffix. Most convert with a tiny, regular change.

| English | Spanish | Example |
|---|---|---|
| -or | -or | doctor → doctor |
| -al | -al | natural → natural |
| -ble | -ble | possible → posible |
| -ic | -ico | automatic → automático |
| -ist | -ista | artist → artista |
| -ous | -oso | famous → famoso |
| -ent / -ant | -ente / -ante | important → importante |
| -tion | -ción | action → acción |
| -sion | -sión | television → televisión |
| -ty | -dad | university → universidad |
| -ment | -mento | moment → momento |
| -ive | -ivo | creative → creativo |
| -ct | -cto | product → producto |
| -ry | -rio / -ría | ordinary → ordinario |
| -ure | -ura | culture → cultura |
| -cal | -co | logical → lógico |

Stress: -or and -al words stress the last syllable, -ble and -ente words the next to last. Accents mark stress and never change a letter's sound.

## The past-tense shortcut

Narrate the past immediately with the -ar preterite pair:

- **-é = I** — hablé, trabajé, compré, visité, tomé
- **-ó = he / she / you** — habló, trabajó, compró, visitó, tomó

Two endings unlock talking about what happened. Expand to -er and -ir verbs (-í / -ió) once the pair is solid.

## False friends — the method's one hazard

Cognate confidence misfires here. The common traps:

| Looks like | Actually means | The English word is |
|---|---|---|
| éxito | success | exit → salida |
| actualmente | currently | actually → en realidad |
| asistir | to attend | assist → ayudar |
| realizar | to carry out | realize → darse cuenta |
| sensible | sensitive | sensible → sensato |
| embarazada | pregnant | embarrassed → avergonzada |
| constipado | congested | constipated → estreñido |
| ropa | clothing | rope → cuerda |

## How it teaches

Question-and-answer ping-pong: ¿Es...? → Sí, ... / Ay no, .... Short rounds, fast wins, warm tone. Madrigal built portable "reminder cards" from index cards for spare-moment review; the Notion Spanish Language Bank is the modern instrument for the same job.
