# Integrations

Plugin and tool connections scoped to Athena. Athena is dormant. Nothing is provisioned, and nothing should be provisioned until the venture reactivates.

Created 2026-08-08 (The Junction) so that the portfolio has no venture without a registry. A dormant venture with an explicit empty registry is legible; a dormant venture with no registry is indistinguishable from one that was simply forgotten.

---

## File placement note

This file sits at `Operations/AI/` rather than `Agents/` because Athena has never been migrated to the seven-studio structure. It remains on the retired nine-department taxonomy, and its governance files – `agent-guidelines.md` and `department-heads.md` – live here alongside it. Placing the registry beside its siblings keeps the venture internally consistent rather than half-migrated.

On reactivation, the migration to seven studios and two shared resources happens first, and this file moves to `Athena/Agents/integrations.md` with it.

---

## Plugin Routing Principle

Athena owns its plugins. None exist. While dormant, no Athena work should require live platform access; any task that appears to is a signal that the venture is reactivating and should be raised as such rather than served from a neighbouring credential.

Under no circumstance is another venture credential used for Athena work. A dormant venture reaching for the Five Points Stripe account or the personal Notion workspace is exactly the boundary failure the segmentation rules exist to prevent.
