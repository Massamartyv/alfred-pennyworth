# Agent Guidelines -- Marty Gras

Rules for AI agent behaviour within Marty Gras. Read this before executing any task scoped to this venture.

---

## Execution Tiers

### Tier 1 -- Full Autonomy

Execute without approval:
- Drafting content -- newsletter editions, social posts, podcast outlines, show notes
- Research -- cultural trends, audience insights, competitive analysis
- Data extraction -- analytics summaries, performance metrics, audience data
- Generating templates and content variations
- Updating registries and indexes

### Tier 2 -- Execute Then Notify

Act within defined parameters, then notify for review:
- Scheduling content via Buffer -- must be reviewed before going live
- Populating episode templates and newsletter templates
- Creating performance reports from analytics data
- Updating SOPs with improvements
- Guest outreach drafts -- must be reviewed before sending

### Tier 3 -- Approval Required Before Execution

Do not proceed without explicit approval:
- Publishing any content externally -- newsletter, podcast, social
- Sending messages to sponsors, guests or collaborators
- Committing to partnerships, sponsorship terms or collaboration agreements
- Modifying brand voice or editorial direction documents
- Making financial decisions or commitments
- Accepting or declining sponsorship offers
- Registering for new platforms or services

---

## Red Lines

1. Never publish content without human review.
2. Never deviate from the documented brand voice in `personal-brand-identity.md` and `martyv-identity.md`.
3. Never send outreach to sponsors, guests or collaborators without approval.
4. Never modify source documents in Product Development/ without approval.
5. Never commit to any partnership, collaboration or sponsorship terms.
6. Never cross personal and business data boundaries.
7. Never use copyrighted music, images or content without verified licensing.

---

## File Interaction Rules

- **Read freely.** Any file in this venture is accessible for context.
- **Write to drafts.** Create new files in appropriate locations freely.
- **Update registries.** Keep `_clients-registry.md` and `_sop-registry.md` current.
- **Never delete.** Move to Archive, never delete. If something is wrong, flag it.
- **Always use frontmatter.** Every new file gets the standard YAML frontmatter.

---

## Context Loading

When starting a task:
1. Read `_index.md` at the venture root -- orient to the venture
2. Read this file -- know the rules
3. Read the relevant department `_index.md` -- find the right files
4. Read the specific files needed for the task
5. Do not load everything. Be surgical.

---

## Brand Voice Loading

Any task that produces audience-facing content must load:
1. `Context/personal-brand-identity.md` -- the voice
2. `Context/martyv-identity.md` -- the brand profile
3. `Context/creative-director.md` -- the aesthetic sensibility

These three files govern everything the audience sees, hears or reads.
