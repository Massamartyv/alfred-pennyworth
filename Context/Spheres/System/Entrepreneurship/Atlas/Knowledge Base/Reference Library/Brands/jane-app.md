# Jane App

**Who** – A cloud-based practice management and EHR platform built for allied health practitioners – chiropractors, physiotherapists, massage therapists and naturopaths among them. The likeliest first EHR integration target for Atlas, identified from the clinical advisor profile.

**Why aligned** – Jane App earns a place because Atlas must live inside the platform its first clients already run. The question is never whether to integrate with Jane App – it is how deeply, and how to surface Atlas intelligence without disrupting the workflow Jane App's users have built their practices around. This is a reference for integration architecture, API depth, and what the allied health practitioner expects from their daily software experience.

**The proposition** – Jane App demonstrates that practice management software can be genuinely beloved by clinicians when it is built around how they actually work, not how a software architect imagines they work. The UX warmth, onboarding quality and practitioner-facing copy set a clear bar: Atlas must feel as native to the Jane environment as Jane itself. The API surface, authentication model, post-back semantics and schema design are the technical layer Atlas reads before writing a single integration line. The relationship with this platform is instructive in a second sense: Jane App's success in allied health is partly because it did not try to own primary care. That is the pattern Atlas replicates – go deep in one under-served category, build trust through fidelity to how that category actually works.

**Canon** – The Jane App allied health platform and its practitioner community; the onboarding and in-product communication standard; the API surface documented at `Atlas/Knowledge Base/EHR/jane-app.md` (planned).

**Pull for** – positioning, integration-architecture, ehr-integration, offer-design.

**Trend read** – Pending enrichment. Jane App has expanded steadily in the allied health space, particularly in Canada and Australia. The chiropractic penetration rate in North American markets, and whether Jane App has gained or ceded ground to ChiroTouch, requires a current enrichment pass before Atlas commits final integration sequencing.
