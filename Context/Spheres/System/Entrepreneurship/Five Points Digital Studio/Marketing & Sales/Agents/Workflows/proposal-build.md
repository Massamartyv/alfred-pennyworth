# Proposal Build

The fourth stage of the client flywheel – Propose. Offer architecture assembled against the approved dossier, the Two Prices structured, and the case built inside a Proposal Template. The heaviest copy load after Attract – one specialist dispatch carries the entire client-facing narrative.

---

## Reconnaissance

**Role:** Proposal Architect
**Crew:** Researcher

- Pull the approved dossier from Discover – client brief, offer recommendation, engagement terms draft
- Pull the recommended offer from Product Development – the catalogue that offer-creator builds and registers – and confirm current pricing, deliverables and guarantee from the live offer file, never from memory
- Select the matching skeleton from Proposal Templates for the offer type – retainer, project or bundle
- Gather client-specific proof – comparable case studies, relevant results, category-specific reference points

**Output:** Proposal reconnaissance brief – confirmed offer, template selection, proof points.

---

## Direction

**Role:** Proposal Architect
**Crew:** Creator

- Confirm the value stack – core offer plus bonuses, framed against the dossier's dream outcome
- Structure the Two Prices – lead with the inaction ledger (the quantified cost of the problem persisting) before the fee, so the fee lands as the smaller number
- Set the proposal's narrative arc – how the dossier's problem becomes this offer's solution

**Output:** Proposal brief – value stack, pricing structure, narrative arc.

---

## Execution

**Role:** Proposal Architect
**Crew:** Creator

- Populate the selected Proposal Template with the confirmed offer, pricing and value stack
- Dispatch to the **sales-copy** skill for the long-form narrative – the problem-to-solution arc, the value stack presentation, the anchoring script that leads with the inaction ledger before the fee
- Assemble the complete proposal – cover, narrative, offer stack, pricing, guarantee, terms summary, call to action

**Output:** Draft proposal, formatted to the Proposal Template.

---

## Critique

**Role:** Offer Steward
**Crew:** Reviewer:Scrutiny

- Run the grammar audit (invoke grammar-nazi)
- Verify every price and deliverable against the live Product Development file
- Confirm the Two Prices rule is honoured – the cost of inaction stated before the fee
- Confirm the guarantee statement matches the suite guarantee doctrine for this offer's price point
- Evaluate against the four criteria: brand alignment, originality, craft and finish, emotional resonance (`Marketing & Sales/Agents/Criteria/quality-rubric.md`)

**Output:** Proposal critique report – pass, or revision notes.

**Hard gate: human approval required before proceeding.** Client-facing – no proposal reaches a prospect without review, per `Agents/agent-guidelines.md` Tier 3 and Red Line 3.

---

## Release

**Role:** Sales Lead
**Crew:** Broadcaster

- Send the approved proposal to the client through the appropriate channel – email, in-person walkthrough or portal
- Log the send in the Five Points CRM – offer, price, date
- Schedule the follow-up that carries this engagement into Close

**Output:** Proposal delivered to client, pipeline stage advanced to Close.
