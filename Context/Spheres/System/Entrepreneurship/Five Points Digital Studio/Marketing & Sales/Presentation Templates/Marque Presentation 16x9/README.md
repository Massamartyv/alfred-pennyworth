# Marque Presentation - 16:9

Template v1. The master deck framework of the house and the first instrument
of The Letterpress: ten 1280 x 720 sheets on the Quintessence ratification of
24 July 2026 - bone paper against one ink, the mismatched serif pair, IBM
Plex Mono for indices and metadata, colour supplied by a single voice through
the `data-voice` contract.

The structural skeleton is stripped from a reference editorial trend report
(Musicbed Commercial Filmmaking Trend Report 2026) by operator direction:
framework only, every visual decision remade in the house design world. Built
from the design system at `~/.claude/skills/five-points-design/` and the
instrument pattern of `Marketing & Sales/Proposal Templates/Commissioning Proposal A4/`.

## Files

- `deck.html` - the framework. Duplicate per instance and fill the slots.
- `specimen.html` - a filled instance describing the framework itself. Gate
  evidence and visual reference; derive from `deck.html`, not from this file.
- `build.py` - render to 16:9 PDF with the overflow gate. `--proof` writes
  per-sheet PNGs to `proof/<stem>/`.
- `gate.py` - copy-convention gate on the rendered text, plus the serif
  weight audit. The unfilled framework fails the slot check by design; an
  instance must pass clean.
- `fonts.css` + `fonts/` - local woff2, copied from the proposal template.
  Generated; do not hand-edit.
- `assets/` - the Quintessence mark: `mark.svg` (as shipped by the design
  system), `mark-ink.svg` and `mark-parchment.svg` (register renderings
  generated by injecting a root fill), `favicon.svg` (the reduction).

## Rendering

```bash
uv run --with playwright python build.py --proof
uv run --with playwright python build.py --src my-instance.html --proof
uv run --with playwright python gate.py --src my-instance.html
```

System Chrome does the rendering and every font is local, so the render needs
no network. The overflow gate measures every sheet and refuses to write a PDF
that has lost content; trim the copy or re-space the sheet rather than raising
the tolerance.

## Slot register

Every instance field is a `«GUILLEMET SLOT»` set in mono on a voice tint, so
anything unfilled is impossible to miss in a proof. `gate.py` fails on any
survivor, which makes it the last check before a send.

| Slot | Where |
|------|-------|
| `«TITLE LINE ONE/TWO/THREE»` | cover, stacked display |
| `«THE KICKER LINE ABOVE THE TITLE»` | cover |
| `«SPECIMEN 01..04»` | cover facet captions |
| `«DOCUMENT FAMILY»` `«EDITION»` `«PRINCIPAL»` `«CITY»` `«YYYY»` | cover meta, running heads |
| `«DOCUMENT TITLE»` | running heads |
| `«THE DOOR THIS DOCUMENT SERVES, IN ONE SENTENCE»` | sheet 2, statement B |
| `«PART ONE»` `«PART TWO»` `«CHAPTER ONE..FIVE»` `«THE CLOSE»` | contents, handover |
| `«THE THESIS, STATED ONCE.»` + two argument columns | sheet 4 |
| `«THE WITHHELD LINE BENEATH IT»` | chapter ghost lines |
| chapter claim, body columns, invitations | sheets 5 and 8 |
| `«FIGURE 01..03 · CREDIT»` | figure captions, sheets 2, 5 and 8 |
| `«THE HINGE LINE BETWEEN THE TWO PARTS»` | sheet 7 |
| `«THE AUTHORITY LINE, QUOTED»` `«NAME · STANDING»` + support columns | sheet 9 |
| `«ONE WORD.»` + closing columns + `«BOOKING LINE · LINK»` | sheet 10 |

Fixed studio-side canon changes rarely and on purpose: the spine sentence on
sheet 2, the rebuild lines on sheet 4, the interstitial declaration, the
three-door line on sheet 7 and the commissioning panel copy. The argument of
the studio is the same for every principal; a deck that re-argues it from
scratch each time is a deck that does not believe it.

## Design decisions worth knowing

**One voice, one attribute.** `<body data-voice="coral">` sets the whole
document; swap in `cornflower`, `sun`, `lavender` or `sage` and every tab,
tint, facet and rule follows. One voice per document, absolute. The five meet
only in the mark.

**Two registers, content-led.** Bone is the working register, ink the
ceremonial. `data-register="ink"` on a sheet flips the tokens, and the voice
steps up to its light grade for contrast. The cover, the handover, one chapter
and the closing flood run ink here; a derivation chooses its own rhythm.

**The ghost line.** The Withholding attribute made typographic: the second
thought under every chapter head, serif at 7% opacity. Headlines imply; the
ghost almost says it; body copy names it.

**The aside device.** The reference deck frames asides in giant drawn
parentheses. Parentheses are banned by the fingerprint, so the aside sits
between two vertical voice rules instead - the same breath, legal punctuation.

**Sentence case throughout the serif.** The reference deck shifts to all caps
in its second half; the house does not shout. The register shift alone carries
the change of part. All-caps lives only in the grotesque label and the mono
annotation voice.

**The mark on ink.** Cover and closing carry `mark-parchment.svg` - the one
colour per rendering rule - at 92px, the sign grade. Seams read as noise in a
screen-scale raster and resolve at print resolution; do not thicken the stroke.

**The register variants carry literal colour, not `currentColor`.** Corrected
2026-08-06, during the stationery build. The upstream `mark.svg` fills with
`currentColor`, which is correct for inline SVG where the host sets `color`.
Loaded through an `<img>` tag the SVG becomes an isolated document,
`currentColor` resolves to black regardless of the root fill, and the
parchment mark rendered ink-on-ink - all but invisible on the cover and the
closing flood. Both variants now carry their literal hex. The note above
about seam noise is true of the mark at small scale and was, until this was
found, also serving as an explanation for the defect; read it as describing
seams only. Never copy `currentColor` geometry into a variant meant for an
`<img>`.

**Print border on ink.** The ratified `--border` at 0.14 alpha disappears when
printed on obsidian, so this document runs the proposal's print-tuned 0.30.

**Registers re-assert their colour.** `data-register="ink"` sets the literal
`color` and `background` alongside the tokens, so the register works at any
depth - on a whole sheet or on a nested half like the contents spread.
Redefining custom properties alone cannot recolour text whose colour was
resolved on an ancestor; the re-assertion is both the fix and the lesson, and
the gate's invisible-text audit now guards the whole class of failure.

**Running heads on split sheets.** The contents spread carries its head on the
bone half only, and the closing sheet drops the house field because the mark on
the facing flood carries the identification. Deliberate asymmetries; every
full-width sheet shows all four fields.

**The quiet ninth sheet.** The pull-quote page holds its top band and leaves
the rest of the sheet empty on purpose - the rest beat before the close, set
against the density of the chapters around it. Do not fill it.

## Copy conventions

Per the brand fingerprint quality gate V6, enforced against the rendered text:
no em dashes - en dashes only - no contractions, no parentheses, no Oxford
comma, no exclamation marks, no possessive apostrophe-s, British spelling,
numerals for 10 and above, the middle dot separates metadata. `gate.py`
enforces all of it, plus runts (a single word stranded on a paragraph's last
line), the serif weight ceiling of 400 and an invisible-text audit - any text
whose contrast against its effective background falls below 1.6:1 at legible
opacity fails the gate. The gate still cannot judge copy quality or layout
taste; the behavioural review tier owns that.

## Deriving a sibling document

1. Start from `deck.html`. Keep the stylesheet; take the components the
   document needs and delete the sheets it does not.
2. Declare the document's voice on `<body data-voice="...">`. One voice.
3. Keep the running head, the component designations and the slot discipline.
4. Fill studio canon once, per document type; leave instance fields as slots.
5. Renumber by hand after any sheet deletion or reorder. Folios, running-head
   page numbers, contents entries and component designations are static text
   with no computed source of truth; cross-check the contents page against the
   folios before the gate, because nothing in the pipeline catches a
   desynchronised table of contents.
6. Ship with `build.py` + `gate.py` + `README.md` naming the inherited
   components and the slot register, per the validation contract of The
   Letterpress.
