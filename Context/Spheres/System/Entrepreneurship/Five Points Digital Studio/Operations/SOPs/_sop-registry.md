## Agent Instructions

- Before executing a repeatable process, check this registry for an existing SOP.
- If no SOP exists and you execute a process three or more times, draft one.
- Each SOP must include: trigger, steps, decision points, escalation rules, success criteria.
- SOPs should be written as executable playbooks with decision trees, not reference docs.
