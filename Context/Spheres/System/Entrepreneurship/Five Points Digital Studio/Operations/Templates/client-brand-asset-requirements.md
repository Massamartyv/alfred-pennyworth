# Five Points Digital Studio — Client Brand Asset Requirements

**Purpose:** A comprehensive inventory of every brand asset, credential, operational resource and content asset required from the client to execute each offer in the Five Points suite. Designed to be collected upfront at onboarding so no follow-up requests are necessary during delivery.

**How to use this document:** When a client engagement is scoped, pull the asset requirements for each offer included in the engagement. Combine them into a single onboarding asset request. Remove duplicates. Send once.

---

## Universal Assets (Required for Every Engagement)

These apply across all tiers and all pillars. Collect these regardless of which offer is scoped.

**Visual and Brand Assets**
- Primary logo file (vector format: SVG, EPS or AI preferred, PNG at minimum)
- Logo variations if they exist (horizontal, stacked, icon only, light background, dark background)
- Brand color codes (HEX, RGB and CMYK)
- Brand fonts (font files or font names with license information)
- Existing brand guidelines document (if one exists, any format)
- Approved brand photography (high resolution, organized by category if possible)
- Headshots of key team members (high resolution, professional)

**Business Information**
- Legal business name and DBA (if different)
- Business address
- Primary phone number
- Primary email address
- Website URL
- Business description (elevator pitch, one paragraph)
- Year founded
- Industry and sub-industry
- Key products or services (brief list)
- Target audience description (who they serve)
- Top three to five competitors (names and URLs)

**Points of Contact**
- Primary contact name, title, email and phone
- Secondary contact name, title, email and phone (if applicable)
- Decision maker name and title (if different from primary contact)
- Preferred communication channel (email, Slack, phone)
- Approval authority: who can approve deliverables

## ASSET DELIVERY SPECIFICATIONS

**File format preferences:**
- Logos: SVG (preferred), EPS, AI, PNG (transparent background, minimum 1000px wide)
- Photography: JPEG or PNG, minimum 2000px on the longest edge, 300 DPI for print
- Documents: PDF, DOCX or Google Docs links with comment access
- Design files: Figma links (preferred), Sketch, Adobe XD, or PSD
- Spreadsheets: XLSX, CSV or Google Sheets links
- Video: MP4 (H.264), MOV or original camera files
- Audio: WAV, AIFF or high bitrate MP3 (320kbps)
- Fonts: OTF or TTF files with license documentation

**Credential delivery:**
- All credentials should be shared via a secure method (1Password, LastPass share, or a temporary secure link)
- Never send credentials via plain email
- API keys and tokens should be scoped to the minimum permissions needed for the engagement
- Five Points will provide a secure credential intake form for each engagement

**Folder structure recommendation:**
Clients should organize assets into the following folders before delivery:
- `/logos` — all logo files and variations
- `/photography` — organized by category (team, products, workspace, events)
- `/documents` — brand guidelines, strategy docs, existing collateral
- `/copy` — website copy, email templates, ad copy, messaging docs
- `/credentials` — shared securely via the designated method
- `/video` — raw footage, edited pieces, b-roll
- `/audio` — music, voiceovers, podcast files
