# Five Points Lookalike Engine — Closed-Loop Lead Gen

**Goal:** keep the pipeline full by turning responders into a template and mining the network for more of them. Every message aims at one outcome — an appointment. Appointment → Lead → Marty closes.

## Two-stage funnel
The engine now runs on two stages that feed each other:

- **Stage A — Connect (top of funnel).** Grow the lookalike pool with **blank (no-note) connection requests** to net-new, DNA-fit prospects who are not yet connected. Blank requests accept at a higher rate and dodge LinkedIn's noted-invite limits on free accounts. Accepted requests graduate into the 1st-degree pool.
- **Stage B — Convert (the messaging loop).** Newly accepted connections join the existing pool and, next cycle, receive the AI-discovery message. Everything from reply-capture onward is Stage B.

The two run in one cadence: each pulse stages a Connect batch and a Message batch, both for approval. Accepts from Stage A become eligible for Stage B the following pulse.

## The loop (one cycle)
1. **Capture replies.** Check inbox for responses to the outreach. Flag anyone who wants to talk / books as **appointment-ready** for Marty.
2. **Update the DNA.** For each positive responder, extract: industry, seniority, segment, geography, and headline/psychographic signals. Aggregate into the weighted winning profile. Traits that over-index among responders gain weight.
3. **Re-score both pools.** Score the remaining 1st-degree connections (Stage B) and the net-new prospect pool (Stage A) against the DNA. Exclude everyone already contacted or already sent a request.
4. **Surface, do not send.** Present to Marty: reply updates, the next Message batch (~25), and the next Connect batch (~25). **Approve-each-batch** — nothing sends without his greenlight.
5. **Send approved batches.**
   - *Connect:* fire the approved blank connection requests. Pace to stay under LinkedIn's weekly invite ceiling (~100–200/week; keep daily well below the throttle line).
   - *Message:* AI-discovery message (personal hook + "how are you using AI / where does it fall short"), thread-aware, steer toward a call. No booking link — hand booking to Marty.
6. **Track accepts.** Next pulse, check which Stage-A requests were accepted; move accepts into the Stage-B message queue.
7. Repeat. Network first; Stage A sourced from net-new lead files now, from Sales Navigator once the DNA is proven.

## Connect batch — source & files
- Ready targets and staging live in `connection-request-queue.csv` (same folder). Columns: status, target, role, company, location, segment, linkedin, request_type, note.
- **Ready** rows have a resolved LinkedIn profile and can be requested as-is (blank note).
- **Priority – resolve DM profile** rows are high-fit verified-shortlist accounts (luxury RE, med spa, aviation, homebuilders) that need a named decision-maker profile resolved via live search before a request can fire.
