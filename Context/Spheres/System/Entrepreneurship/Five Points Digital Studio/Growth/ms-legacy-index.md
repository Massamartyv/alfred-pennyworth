## Key Sales Context

- Pricing sweet spot: $5K-$8K+ monthly retainers
- Never discount -- add value instead
- Value stack: show $18K+ perceived value before naming price
- Proposal to close target: 50% within 14 days
- Bronze workshop is the front door to Gold retainers

## Agent Instructions

- All proposals must use templates from Proposal Templates/.
- Pricing must reference Product Development/ offer files -- never quote from memory.
- All proposals require human approval before sending to client.
