# Finance

Revenue models, financial projections, tax compliance and performance metrics for Five Points.

## Structure

```
Finance/
  _index.md              – This file
  Agents/                – Department-specific agents, workflows, criteria
    _index.md            – Agent roster and workflow registry
    Workflows/           – Named Manor Protocol sequences
    Criteria/            – Quality rubrics and evaluation standards
```

Note: the Revenue/, Planning/, Tax/, Cost Management/ and Metrics/ subdirectories referenced in earlier versions of this file were never built. Pricing, revenue and tax state live in Notion – see Key Financial Context below.

## Key Financial Context

- **Live revenue state:** Notion Five Points workspace (Finance dashboards, Stripe). Milestone rungs are waypoints on the enterprise-value ladder – never terminal targets.
- **Owner distribution:** 40% of net revenue
- **S-Corp election:** Triggered the moment MRR sustains above $10K – an early administrative step on the way to a structure built for scale (entity architecture reviewed annually against the trajectory).
- **Tool overhead:** ~$3,500/month fixed
- **Stripe:** Active via Five Points account (MCP connected)

## Agent Instructions

- Financial decisions are always Tier 3 (approval required)
- All pricing references Notion Five Points workspace and the Product Development/ offer files – never quote from memory
- Never modify pricing without explicit approval
- Tax compliance dates are tracked in Notion Five Points workspace – check approaching end of each quarter
- Revenue data references Stripe and Notion CRM – never estimate
