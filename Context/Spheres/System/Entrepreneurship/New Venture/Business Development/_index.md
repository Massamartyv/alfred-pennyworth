# Business Development

Lead generation, qualification, partnerships, and pipeline development. Playbooks and frameworks that agents use to find, qualify, and warm prospects before they enter the sales process.

## Contents

| File | Purpose |
|---|---|
| ideal-client-profile.md | ICP criteria, trigger events, red flags |
| lead-qualification-framework.md | Scoring rubric for inbound and outbound leads |
| outbound-sequences.md | Email sequence templates for outreach campaigns |

| partnership-framework.md | Partner tiers, referral structure, co-marketing |
| case-study-framework.md | Template for documenting client results |
| pitch-deck-framework.md | Async and live pitch structures |
| networking-playbook.md | LinkedIn strategy, events, community presence |

## Agent Instructions

- Load `ideal-client-profile.md` before qualifying any prospect.
- Use `outbound-sequences.md` to draft personalized outreach. Personalization flags are marked with `{variables}`.
- `discovery-call-framework.md` provides the call structure -- prepare pre-call research briefs using this format.
- When a deal closes, use `case-study-framework.md` to begin documenting results from day one.
- Never commit to pricing, timelines, or scope during outreach. Escalate to the sales process.

## What Belongs Here
