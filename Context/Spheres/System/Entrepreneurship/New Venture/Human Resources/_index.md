## Agent Instructions

- Reference `contractor-roles.md` when scoping work that might need a contractor.
- Use `contractor-onboarding.md` as a checklist when bringing someone new onto a project.
- `culture-and-values.md` informs how communication templates and internal docs should sound.
- Never commit to compensation terms without approval.
