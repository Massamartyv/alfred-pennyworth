# Knowledge Base – Agent Roster and Workflow Registry

Knowledge Base is a department, not a shared resource. It feeds every other department with researched ground to work from. Agents here run mostly in Reconnaissance phase. The Industry Researcher, Guest Behaviour Analyst and Competitive Intelligence roles carried forward from the former Strategy studio at The Restoration, 2026-09-10.

---

## Specialist Roles

| Role | Function | Primary Phase | Primary Crew |
|---|---|---|---|
| **Knowledge Steward** | Owns the integrity and retrieval of the knowledge base | All | – |
| **Researcher** | Gathers industry research, case studies, methodologies | Reconnaissance | Researcher |
| **Industry Researcher** | Hospitality trends, emerging formats, category shifts, reference brands | Reconnaissance | Researcher |
| **Guest Behaviour Analyst** | Segment mapping, booking patterns, spend behaviour, loyalty drivers | Reconnaissance | Researcher |
| **Competitive Intelligence** | Adjacent concepts, local competitive set, positioning gaps | Reconnaissance | Researcher |
| **Synthesiser** | Turns raw research into reusable briefs and methodologies | Execution | Creator |
| **Librarian** | Maintains taxonomy, tags, cross-references | Release | Broadcaster |
