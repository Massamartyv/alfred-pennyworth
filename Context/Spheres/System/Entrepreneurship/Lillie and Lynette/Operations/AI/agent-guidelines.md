# Agent Guidelines -- Lillie and Lynette

Rules for AI agent behaviour within Lillie and Lynette. Read this before executing any task scoped to this venture.

---

## Execution Tiers

### Tier 1 -- Full Autonomy

Execute without approval:
- Research -- market analysis, competitor scouting, location data, hospitality trends
- Data extraction -- industry benchmarks, demographic analysis, real estate listings
- Drafting internal documents -- concept briefs, planning outlines, vendor comparison matrices
- Generating templates and checklists
- Updating registries and indexes

### Tier 2 -- Execute Then Notify

Act within defined parameters, then notify for review:
- Drafting guest-facing copy -- menu descriptions, event promotions, marketing language
- Creating financial projections and models
- Populating vendor and partnership evaluation documents
- Updating SOPs with improvements
- Preparing outreach drafts for vendors, landlords or partners

### Tier 3 -- Approval Required Before Execution

Do not proceed without explicit approval:
- Sending messages to vendors, partners, investors or landlords
- Committing to lease terms, vendor contracts or partnership agreements
- Publishing any content externally -- website, social media, press
- Making financial decisions or commitments of any kind
- Modifying brand identity or service design documents
- Registering for new platforms or services
- Submitting licence or permit applications

---

## Red Lines

1. Never commit to any financial obligation without human approval.
2. Never sign, accept or agree to any terms -- lease, vendor, partnership or otherwise.
3. Never publish guest-facing content without human review.
4. Never send outreach to any external party without approval.
5. Never modify source documents in Product Development/ without approval.
6. Never cross personal and business data boundaries.
7. Never share proprietary concept details outside approved channels.

---

## File Interaction Rules

- **Read freely.** Any file in this venture is accessible for context.
- **Write to drafts.** Create new files in appropriate locations freely.
- **Update registries.** Keep `_clients-registry.md` and `_sop-registry.md` current.
- **Never delete.** Move to Archive, never delete. If something is wrong, flag it.
- **Always use frontmatter.** Every new file gets the standard YAML frontmatter.

---

## Context Loading

When starting a task:
1. Read `_index.md` at the venture root -- orient to the venture
2. Read this file -- know the rules
3. Read the relevant department `_index.md` -- find the right files
4. Read the specific files needed for the task
5. Do not load everything. Be surgical.
