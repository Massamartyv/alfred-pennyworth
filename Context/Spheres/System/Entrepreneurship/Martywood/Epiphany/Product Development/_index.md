# Product Development – Epiphany

Build documentation for the essay line. Essays – drafts and shipped pieces, the two-deep buffer. Three streams, one form, one cadence – the Bridge, the Instrument, the Diary. "Quantum Entanglement" is the Diary prototype and lives here.

### What Does Not Belong Here

- Brand identity work – that lives in Foundation
- Anything a parent department already owns – file it with the parent and link from the sub-brand index
- Live state – Notion holds status, stages and metrics, never this folder
