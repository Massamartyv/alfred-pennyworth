# Eternal Raspberries – Sub-Brand Index

The product line. Notion systems sold as agent-ready infrastructure, seated as the fourth property of Martywood alongside Marty V, Marty Gras and Epiphany. Established 2026-09-10.

A sub-brand keeps a light structure inside its parent venture rather than the full nine-department layout: Foundation for its fingerprint, Product Development for build documentation. It inherits Martywood governance – Agents/, brand fingerprint authority, approval gates – until its own Foundation matures.

## Positioning

Nearly every Notion template on the market is built for a human to look at. These are built for an agent to operate.

The buyer is not purchasing a layout. They are purchasing the schema work their assistant needs before it is useful: a description on every database and every property, deterministic naming with no ambiguous duplicates, invariants stated rather than implied, and an Agent Brief the model reads once before it runs the system on the buyer's behalf.

This is a category claim rather than a feature, and it carries an obligation. A claim of agent readiness invites verification, and a product that stumbles on an ambiguous property name breaks the claim for the whole shelf.

## Construction standards

Applied to every product in the line.

| Standard | Rule |
|---|---|
| Databases | Inline always, never a full-page link. A semantic coloured built-in icon on each. |
| Views | A primary view chosen for the data, plus a second view named Main carrying the database icon, rendered as a list. Never an unnamed Default view table alone. |
| Headings | None. A framing callout carries the promise, a collapsed Start here toggle carries the teaching. |
| Descriptions | Every database and every property carries one, in plain language. This is what makes the product agent-navigable and it is also house law. |
| Demo data | A minimal skeleton – three or four illustrative rows per database, enough to light up relations and formulas. |
| Personal residue | Swept before publication. No real institutions, gyms, suppliers, contacts or account names anywhere in a shipped product. |

## Graduation

The light structure holds until two or more of the following are true: an own revenue line, an own roster, an authored fingerprint that has diverged from Martywood, or three or more active domains. Graduation copies the missing departments from `New Venture/` and rewrites this index to the venture-index shape.
