# Mr Porter

**What** – The menswear retailer named first among the curators of creative-director.md, defined as an "editorial buyer whose filter already matches the taste" and a "reliable secondary storefront" when a specific brand is not carried directly.

**Why aligned** – A curator used as a proxy for judgement, narrowed to menswear. When the exact piece is not sourced direct, Mr Porter's edit is a trusted second pass – the buying already screens for the proportion, fabric and restraint the wardrobe runs on, so the selection does the first filtering. The editorial layer is part of the value: the writing and styling argue for the clothes rather than just listing them.

**The filter** – Trust a menswear selector whose criteria already match yours and let the edit run the first pass. The buying is the taste; the styling and editorial are part of the product, not packaging around it. Use it as the reliable second storefront when the direct source comes up empty, and trust that what clears the filter is worth the look.
