# Kurt Cobain

**Who** – Musician and a named style reference in creative-director.md: "anti-style as style, grunge texture, thrifted layering, effortless nonchalance".

**Why aligned** – The reference for the punk sensibility beneath the composure – the raw, indifferent register the system names as its engine. Anti-style worn so completely it becomes a style is the proof that not trying, fully committed, beats trying too hard. Grunge texture and thrifted layering supply the rawness that keeps the polish honest.

**The formula** – Refuse to look like you tried. Build from texture and thrifted layers, let the fit read worn-in rather than styled. The nonchalance has to be total – half-committed indifference reads as costume. Anti-style only works as style when the disregard is genuine.

**Canon** – the grunge-era thrifted layering as the anti-style template.

**Pull for** – anti-style direction, grunge, restraint, effortless-nonchalance, fashion.
