# Byredo

**What** – The Swedish luxury house (Stockholm, 2006, founder Ben Gorham), built to translate memory and emotion into scent and since extended into cosmetics, leather and eyewear.

**Why aligned** – The reference for fragrance as abstract narrative. Byredo builds on mood and memory rather than classical perfumery, wrapped in minimal branding and strong art direction – the literary, conceptual end of niche. Gorham's fine-art-and-basketball path into perfume is itself a taste story.

**The proposition** – Sell the memory, not the notes. Build an abstract, art-directed world where each scent is a feeling, minimal branding and maximal mood.

**Canon** – Gypsy Water; Mojave Ghost; Bal d'Afrique; the Ben Gorham era through the 2025 Puig handover.

**Pull for** – niche-fragrance, memory-and-mood, art-direction, abstract.
